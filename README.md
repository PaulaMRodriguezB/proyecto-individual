
# 📋 Planificador de Tareas (Task Manager)

Una aplicación web interactiva para gestionar tareas diarias, incluir técnicas de productividad como Pomodoro y escuchar música de ambiente para enfocar el trabajo.

---

## Características Principales

* **Gestión de Tareas:** Crear, marcar como completadas y eliminar tareas.
* **Filtro por Fecha:** Visualizar las tareas correspondientes al día seleccionado.
* **Persistencia de Datos:** Utiliza la API de `localStorage` para guardar las tareas localmente en el navegador.
* **Timer Pomodoro:** Temporizador integrado con intervalos de trabajo (25 min) y descanso (5 min).
* **Reproductor de Música:** Selección de pistas ambientales (Clásica, Jazz, Lo-Fi, Naturaleza) para mejorar la concentración.

---

## Tecnologías Utilizadas

* **HTML5:** Estructura semántica de la interfaz.
* **CSS3 & Bootstrap 5:** Estilos, diseño responsivo y componentes.
* **JavaScript (ES6+):** Programación orientada a objetos (POO), manipulación del DOM y eventos.
* **Web Storage API:** Persistencia en el navegador mediante `localStorage`.
